### **Analytical Breakdown & Technical Specifications**

#### **1. Admissions Desk & Enquiry Management**
*   **Student Enrollment / Registration:**
    *   Triggers: Registration action -> Cross-verification -> Approval flow.
    *   Parameters on Registration/Close state:
        *   `Remark`: Text field for storing conversation logs.
        *   `Probability`: Percentage score for admission likelihood.
        *   `Next Alert Date`: Date-time picker for follow-up scheduling.
        *   `Attachment Module`: File upload component for receipt/documents (e.g., online fee screenshot).
        *   `Update Button`: Commits changes and updates the log tree.
    *   **Visual Representation:** Tree structure UI showing lifecycle tracking (Enquiry -> Registration -> Verification -> Approval).

*   **Approval Flow Settings:**
    *   Configurable via Settings module (`Settings -> Approval Flow`).
    *   Multi-level approval hierarchy support (e.g., Level 1, Level 2).
    *   Assignment Modes:
        *   **Manual Assign:** Approver selects a specific active counselor from a dropdown upon approval.
        *   **Auto Assign (Bulk/Excel):** Bulk upload via Excel/CSV. Interface maps bulk leads to selected counselors with an allocation limit multiplier (`Number of Enquiries` input field to auto-set sequential allocation).

*   **Dialer Integration Configuration:**
    *   Settings Toggle: `Dialer Enable` / `Not Enabled`.
    *   When Enabled: A `Call` button appears on the enquiry feedback screen.
    *   Telephony backend: Internet IP / VoIP integration.
    *   Call Logging: Automatic system call recording associated with the specific enquiry log, with backend date-wise backup retention policies.

*   **Fee to Admission Approval Gate:**
    *   Conditional workflow: Registration Fee Paid $\rightarrow$ Approval Required? (Yes/No).
    *   If Yes: Blocks final admission form accessibility until the designated approver authorizes the record.
    *   UI components: Dedicated list view for the approver showing pending Universal Identification Numbers (UIDs).

---

#### **2. Dashboard & Search Architecture**
*   **Dashboard Layout:**
    *   Removed clutter; focused metric distribution.
    *   Counselor performance widgets displaying open vs. closed enquiries.
    *   Global Quick-Search Bar: Search by Candidate Name, Phone Number, or Enquiry Number.
    *   Pagination: Implemented on enquiry list grids (e.g., 10-15 records per page).
    *   Master Enquiry Feedback Page: Detailed profile view containing status selectors, call logs, and action history.

---

#### **3. Faculty HRMS & Staff Onboarding**
*   **Onboarding Process:**
    *   Removed intrusive pop-up designs; transitioned to inline page layout (`On-board Staff` view).
    *   **Phase 1 (Quick Onboarding):** Minimal fields required (Name, Mobile Number) to instantly generate an Employee ID.
    *   **Phase 2 (Detailed Profile):** Extended tabbed layout for:
        *   Parent details (Father's/Mother's name).
        *   PAN Card, Bank details, and Documentation (e.g., PAN card, canceled cheque, scanned documents).
        *   Additional Roles and privileges mapping.
    *   **Emergency / Immediate Information Tab:** Captures high-priority contact details for immediate record generation.
